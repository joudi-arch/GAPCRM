# Presentation runbook

1. Run `npm run qa` before delivery.
2. Present from `npm run dev -- --host 127.0.0.1 --port 4173`; use `?lite` if the venue GPU is unreliable.
3. Use Chrome at 100% zoom and 16:9 output. Confirm sound is off before the room opens.
4. Dry-run Harley → Fit transition, the 90-day ask, and the final return-to-top control.
5. Keep `?print` open as the static backup and export it to PDF before travel.
6. If live 3D degrades, continue: authored posters preserve every scene and all pitch content remains readable.
